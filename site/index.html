What gets roasted

H1

Headline

Is your H1 benefit-first or a company-name dump? We check framing, length, and count.

CTA

Call to Action

How many CTAs? Any above the fold? Too many dilutes; zero is a disaster.

KB

Load Weight

Page size in KB — a fast proxy for whether mobile visitors bounce before they read a word.

★

Social Proof

Testimonials, logos, user counts, press mentions. We scan for all of them.

[]

Mobile

Viewport meta tag — the minimum bar for not looking broken on a phone.

--

Trust Signals

Privacy policy, contact info, refund guarantee. Missing these kills checkout conversions.

Wc

Word Count

Under 150 words is too thin; over 3000 is a wall. We flag both extremes.

Og

Meta Description

Your Google snippet — missing or too long means Google writes it for you, badly.

Alt

Image Alt Text

Accessibility and SEO baseline. We count the images missing alt attributes.

Run it yourself — free

pip install requests beautifulsoup4 python3 roast.py --url https://yoursite.com --output report.md

Download roast.py from GitHub. No API key. No account. Runs anywhere Python 3.9+ is installed.
